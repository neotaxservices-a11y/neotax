# PracticeDesk Pro

A secure-by-design starter web application for a multi-user Indian tax and accountancy practice. Built with Vite, Supabase Auth/PostgreSQL/Storage, Netlify Functions, jsPDF and optional Razorpay/Resend integrations.

**START HERE:** [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)

Includes client directory with archive/delete, staff logins and assignments, compliance task tracker, expiring client document requests and private uploads, quotation/GST invoice A4 PDF output, part receipts, Razorpay payment-link/webhook integration, optional email reminders and WhatsApp prefilled messages, company logo/branding, chart of accounts and balanced journals, reports and conservative offline-v4 **client master** import.

**Limitations:** Not deployed; no secrets included; production access controls, email and payment flows must be tested in your configured services. No unattended WhatsApp API messaging, no bank-feed reconciliation, no automatic bookkeeping postings, no online portal-password vault, and no full migration of old backup documents or financial records. See guide for required checks.
